# Immich Albums, with a client header

The Immich v3.3.3 Albums view is the visual specification: black background, square album covers with rounded corners, semibold two-line names, date ranges and item counts, generous spacing, and collapsible 30px year headings with counts and a divider. Use auto-fill tracks with a 224px minimum so phones naturally show one full-width album while wider viewports gain columns. Album links have no persistent card surface; use the native rounded surface and border only on hover or keyboard focus. Preserve this hierarchy in light mode. The schema's default `#accbfa` accent uses Immich's light primary for readable title hover/focus; non-default page accents and CSS `--pager-accent` overrides retain their authored colors, so their contrast depends on the chosen page background. Do not add marketing cards or a homepage. A functional dark gradient is permitted behind a banner-overlay header for text readability. See the [pinned Immich album grid source](https://github.com/immich-app/immich/blob/v3.3.3/web/src/lib/components/album-page/AlbumCardGroup.svelte), [card source](https://github.com/immich-app/immich/blob/v3.3.3/web/src/lib/components/album-page/AlbumCard.svelte), and [light primary token](https://github.com/immich-app/immich/blob/v3.3.3/web/src/app.css#L76).

Branding sits above the grid: optional banner and logo, title, and short description. Options control colors and left/center header alignment. Public pages have no editor controls. The editor follows Immich's empty album screen: a large borderless ‘Add a title’ field, ‘Add a description’, and a centered ADD ALBUMS / Select albums tile. Selected albums replace the empty state. Use Immich UI's ghost Textarea and Button components, the same Google Sans font and dark primary/surface colors as Immich. Search and Owned/Selected filters live in a native modal album picker. Logo/banner areas on the canvas support file drops, uploading, and a primary Choose from Immich action. The Options panel uses Immich UI Modal, Field, Select, Switch, Button, and PasswordInput with the native surface color and logo header. Appearance, ordering, URL, and sharing controls live there. Custom colors stay collapsed. Do not add photographer-wide defaults. Keep /page/ on one line in the URL field. Preview, Copy link, Options, and explicit Publish/Update remain in the toolbar. Working edits autosave privately with visible saving/failure states. Public content changes only on explicit publication. The page list uses a compact toolbar, search, visible copy actions, and responsive rows.

Use Immich UI for the password input and accessible controls. Reproduce the album presentation with typed components, retaining upstream attribution. Reserve cover geometry before images load and lazy-load below-the-fold covers. Respect reduced motion.

The dev branch adds a Header layout choice for the whole logo/title/description over the banner, preserving alignment and responsive readability. Custom CSS lives in a collapsed Advanced section, with inline validation, a clear action, and a guide link. It styles only the gallery preview/public view; the editor stays native.
