# ImmichPager

**One link. Every shoot.**

Persistent, customizable client album pages for [Immich](https://immich.app). Give a returning photography client one page for all their commissioned work. Select existing albums, customize the header, and keep adding shoots to the same URL.

An independent community companion, not affiliated with the Immich team. Licensed under AGPL-3.0-only.

## Development status

The initial implementation is in progress. Docker setup, screenshots, compatibility, and contributor commands are documented as their implementation is verified.
